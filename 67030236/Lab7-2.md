## 7. คำถามท้ายการทดลอง (Post-Lab Questions)
1. ในโหมด SoftAP Scheme สมาร์ตโฟนส่งข้อมูลหา ESP32 ผ่านโปรโตคอลและ IP Address ใด?
```text
สมาร์ตโฟนจะส่งข้อมูลผ่านโปรโตคอล HTTP/HTTPS (REST API) หรือ Protobuf over HTTP ไปยัง IP Address ค่าเริ่มต้นคือ 192.168.4.1
```
2. หากผู้ใช้ป้อนรหัสผ่าน Wi-Fi ผิดในแอปมือถือ จะเกิด Event ใดขึ้นบน ESP32 (`WIFI_PROV_CRED_FAIL` หรือไม่) และ ESP32 มีพฤติกรรมอย่างไร?
```text
จะเกิดอีเวนต์ WIFI_PROV_CRED_FAIL ขึ้นบน ESP32 และตัวบอร์ดจะไม่บันทึกค่าลง NVS พร้อมทั้งคงสถานะเปิด Provisioning (SoftAP หรือ BLE) ค้างไว้เพื่อรอรับรหัสผ่านใหม่จากแอปมือถือ
```
3. ทำไมผู้ผลิต IoT ส่วนใหญ่จึงมองว่ากระบวนการเชื่อมต่อแบบ SoftAP มีขั้นตอนที่ยุ่งยากสำหรับผู้ใช้ทั่วไปเมื่อเทียบกับ BLE?
```text
เพราะแบบ SoftAP บังคับให้ผู้ใช้ต้องสลับหน้าจอออกจากแอปเพื่อไปต่อ Wi-Fi ของอุปกรณ์ก่อน ซึ่งทำให้การใช้งานสะดุด ขาดการเชื่อมต่ออินเทอร์เน็ต และมักเจอปัญหา OS บนมือถือตัดการเชื่อมต่ออัตโนมัติ ต่างจาก BLE ที่แอปสามารถค้นหาและส่งค่ารหัสผ่านได้เบื้องหลังทันทีโดยที่ผู้ใช้ไม่ต้องออกจากแอป
```
